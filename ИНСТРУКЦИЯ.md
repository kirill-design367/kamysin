# Как менять сайт самому — инструкция для владельца

Сайт устроен так, что все тексты, цифры, контакты и фотографии можно менять
**самостоятельно, без программиста**, через простой редактор в браузере.

---

## 1. Где редактор

Откройте адрес сайта и допишите в конце `/admin`:

```
https://kirill-design367.github.io/kamysin/admin
```

Откроется «Редактор сайта» — тёмная страница с полями по блокам.

---

## 2. Первая настройка (один раз, ~3 минуты)

Чтобы изменения сохранялись прямо в сайт, редактору нужен «ключ» (токен) от GitHub.
Делается один раз.

1. Зайдите на **github.com** под своей учётной записью.
2. Откройте: **Settings → Developer settings → Personal access tokens →
   Fine-grained tokens → Generate new token**.
   Прямая ссылка: https://github.com/settings/tokens?type=beta
3. Заполните:
   - **Token name**: `сайт-камышин` (любое);
   - **Expiration**: 1 год (или «No expiration»);
   - **Repository access** → **Only select repositories** → выберите
     `kirill-design367/kamysin`;
   - **Permissions → Repository permissions → Contents** → поставьте
     **Read and write**.
4. Нажмите **Generate token** и **скопируйте** длинную строку (начинается с
   `github_pat_...`). Показывается один раз — сохраните её у себя.
5. Вернитесь в редактор `/admin`, в разделе **«Подключение к GitHub»** вставьте
   токен в поле **Токен**. Всё, ключ сохранится в вашем браузере.

> Токен хранится только в вашем браузере и никуда больше не отправляется.
> Если открываете редактор на другом устройстве — вставьте токен там ещё раз.

---

## 3. Как менять контент

1. Откройте раздел (например, **«Блок 1 — Первый экран»** или **«Контакты»**).
2. Измените нужные поля.
3. Внизу нажмите **«💾 Сохранить на GitHub (сайт обновится)»**.
4. Через **1–2 минуты** сайт автоматически пересоберётся — обновите страницу сайта
   и увидите изменения.

Что можно менять:

- **Контакты** — телефон, WhatsApp, Telegram, часы работы.
- **Тексты всех блоков** — заголовки, описания, вопросы, слоган.
- **Цифры охвата** («1 500 ящиков», статистику по районам) — блок **«Масштаб»**.
  Можно добавлять и удалять цифры кнопками **+ добавить** / **✕**.
- **Фотографии** — кнопка **«Загрузить…»** рядом с картинкой: выберите файл, потом
  **«Сохранить на GitHub»**.
- **Название компании и ИНН** — блок **«Бренд и реквизиты»**.

> Совет: перед первым редактированием нажмите **«Загрузить актуальное с GitHub»** —
> редактор подтянет то, что сейчас на сайте.

## 4. Куда приходят заявки с формы

В разделе **«Форма — куда уходят заявки»** выбирается способ:

- **WhatsApp** (по умолчанию) — когда человек заполняет форму и нажимает кнопку,
  заявка открывается у него в WhatsApp уже готовым сообщением на ваш номер. Ничего
  настраивать не нужно, кроме номера WhatsApp в «Контактах».
- **E-mail через Formspree** — заявки приходят вам на почту. Нужно:
  1. зарегистрироваться на https://formspree.io (бесплатно),
  2. создать форму, скопировать её ID (вид `xmyzabcd`),
  3. вставить ID в поле **Formspree ID** и выбрать способ **E-mail** (или **И то, и другое**).

Телефон на сайте — крупный и кликабельный: с телефона по нему звонят в один тап.

Сейчас на сайте стоят **заглушки** — замените на настоящее:

| Что | Где в редакторе | Сейчас (заглушка) |
|-----|-----------------|-------------------|
| Название компании | Бренд и реквизиты → Название | РАЗНЕСЁМ |
| Телефон | Контакты | +7 960 000-00-00 |
| WhatsApp | Контакты | 79600000000 |
| Telegram | Контакты | username |
| ИНН | Бренд и реквизиты | 0000000000 |
| Цифры по районам | Блок 4 — Масштаб | примерные |

---

## 6. Если что-то сломалось

- Просто **перезагрузите** страницу редактора — несохранённые правки сбросятся,
  сайт останется прежним.
- Кнопка **«Скачать site.json»** сохраняет все тексты в файл — можно отдать
  разработчику, если понадобится помощь.
- Сам сайт от правок в редакторе сломать нельзя: если сохранение не прошло —
  выведется красное сообщение с причиной, а сайт продолжит работать как был.
